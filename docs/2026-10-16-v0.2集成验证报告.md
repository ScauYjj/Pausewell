## 本轮交付

可执行程序：`artifacts/Pausewell-ui-v02/Pausewell.exe`。Windows x64 自包含包，无需另装 .NET。

根目录 `体验新版界面.cmd` 打开独立演示数据；`启动新版间歇.cmd` 使用正常数据，切换前需从旧版托盘退出旧版。旧程序目录和旧入口仍保留。

已接入：提醒、服药、记录、设置四个入口；普通间隔与固定时刻；逐条启停；药物明确时刻及起止日期；活动计时与明确确认；实际执行和确认时间分开保存；带原因的记录更正；有期限的会议和暂停；会后缓冲与逐项清单；托盘；五种外观的预览、取消、全局保存和重开恢复。

默认暖香槟材质，石墨黑主按钮、香槟开关。灰紫、陶土橙、雾玫瑰、雾蓝保留为可选主题。换肤不重置调度，也不重建正在进行的活动计时。

## 数据保护与版本核对

本轮没有读取、迁移或改写旧版正在使用的提醒数据库，未关闭旧版进程。旧 EXE 的 SHA256 与本轮开始时一致：

`39E1D5CE92A8C6BE8AE58D1CB6BF16D42875EAF91ACA8312F8C3395E677571AC`

新 EXE 的 SHA256：

`C008708F1095F128F522FEFA08AB1A491C80BBFC9680507C5B530D3355E70DEB`

升级机制已使用合成旧版快照测试。将来正式切换时，新版先生成 SQLite 一致性备份再升级；旧版不能直接读取升级后的 schema 2。如需回退，应退出新版后使用升级前备份，不能让旧版覆盖新版数据。

演示数据位于 `artifacts/ui-v02/demo-data`，示例药物默认关闭，普通示例有真实调度。演示入口不修改 Windows 开机启动设置。

## 尚未验收的范围

当前只有一个显示器。真实锁屏、睡眠唤醒、多屏覆盖、跨屏 DPI、文字放大、屏幕共享、完整读屏及长时间运行仍需设备试用。全屏逃生和当前单屏覆盖通过，不等于所有多屏组合通过。轻提示显示与系统音还受 Windows 设置影响。

原稿的局部高光与折射和 Windows 实现存在差异，具体记录在 `design-qa.md`。当前为静态纹理与透明材质表达，不具备 Apple 平台实时光学效果。

尚无自动会议识别、云同步、签名安装包和自动更新。固定时刻按中国标准时间解释；普通间隔使用持久化时间戳，修改系统时间会影响间隔。本地数据库没有加密。
