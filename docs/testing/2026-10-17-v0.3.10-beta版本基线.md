# v0.3.10-beta 版本基线

本次将当前办公 Beta 建立为首个 Git 基线，默认分支为 `main`，使用附注标签 `v0.3.10-beta`。先前阶段没有 Git 历史，不补造那些阶段的提交。

## 纳入与排除

纳入程序源码、原型和设计规范、必要图片资源、第三方图标许可、构建与验证脚本、测试代码及历史阶段文档。

排除整个 `artifacts` 与 `.tools`、所有 `bin/obj`、数据库及 WAL/SHM、运行诊断与 JSONL、个人试用数据、凭据文件、程序包和压缩包。原文件保留在本机，建立 Git 不删除或移动它们。凭据特征检查未发现候选密钥，这只是本轮提交前检查，不作为全面安全审计结论。

文本按 `.gitattributes` 管理行尾，Windows 脚本检出为 CRLF，其余文本使用 LF，UTF-8 BOM 原样保留。少量历史混合换行和行尾空白已整理，没有改变业务逻辑或正在运行的程序。

## 验证与恢复

提交前检查暂存区没有排除类型，`git diff --cached --check` 通过，重新运行当前 51 项核心规则。原生界面、安装和办公 Beta 检查沿用各阶段对应报告，本轮没有重复声称已经重跑。

提交后另存 Git bundle 到 `artifacts/version-control/Pausewell-v0.3.10-beta.bundle`，并使用该 bundle 在隔离目录克隆，检查标签、文件清单和重新构建。该 bundle 只含 Git 版本数据，不含本地数据库、安装包或试用日志；它是同盘恢复副本，不能代替异地备份。

本地核验记录见 `artifacts/version-control/baseline-manifest.json`。创建基线时尚未关联远程仓库；GitHub 同步需要明确的私有仓库地址和相应访问权限，不把本地提交描述成已经上云。

## 后续约定

修复从 `main` 分出 `fix/*`，功能开发使用 `feature/*`。每次修改对应一项问题，相关检查通过后提交，合入时更新版本记录。已共享标签不移动。后续正式发布需要独立完成设备、办公稳定性和视觉验收。
