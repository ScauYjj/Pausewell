# Beta 办公试用

当前进入基本功能冻结后的 Beta 试用阶段。使用已经安装并核对哈希的 v0.3.10，固定独立数据目录 `%LOCALAPPDATA%/PausewellOfficeTrial-v0310`。不导入真实旧数据，不自动创建示例计划，不改开机启动。

## 开始

双击项目根目录“开始办公试用.cmd”。首次打开为空白，先创建一条自己需要的普通提醒，例如每 30 分钟喝水或起来活动。需要验证一次性事项时，另建一条几分钟后的自定义提醒。

设置一次后，使用同一个入口打开会恢复自己的试用计划。关闭主窗口后继续在托盘运行；双击托盘图标可以返回。真正停止提醒请使用“设置 > 退出应用”。独立试用中不提供 Windows 登录自启设置，避免改变正常安装的启动项。

## 结束后收集

双击“收集办公试用结果.cmd”，会打开本机报告文件夹，包含“办公试用记录.md”和结构化汇总。可在 Markdown 里补上问题、发生时间与截图线索，再反馈本次试用结果。

报告只读取受限的本地诊断日志，不复制数据库、原始日志、药名、事项名或备注，不自动发送到任何地方。运行中的应用也可收集，报告会提示未见退出日志可能表示应用仍在运行。

资源按各次进程分别统计，采样空档明确列出。计划到展示间隔可能包含会议、延期与睡眠，不能直接当作调度延迟。日志轮换会限制可观察范围，一份跨越八小时的日志也不自动等于全天验收通过。
