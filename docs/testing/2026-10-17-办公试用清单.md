# 办公试用清单

最新 Beta 入口：根目录 `开始办公试用.cmd`，使用已核对的安装程序及独立空白数据；结果入口为 `收集办公试用结果.cmd`。操作说明见同目录 `2026-10-17-Beta办公试用.md`。原 `体验办公观测版.cmd` 保留演示用途。下面是待人工执行的清单，未勾选表示尚未完成人工验收，工程检查结果另见对应版本报告。

本版试用入口启用本地诊断，设置中的“打开诊断文件夹”可以定位运行日志。日志不写事项名称、药名或备注；每分钟记录一次资源采样，最多两个1MiB文件。发现问题时保留相关时间段的日志与截图，旧日志会随限额轮换。含 `origin=verification` 的会话/电源日志来自工程合成信号，不能当成真实锁屏、睡眠证据。

| 状态 | 操作 | 应观察的结果 |
| --- | --- | --- |
| [ ] | 新增一条1分钟的普通提醒，完成一次 | 到期提示；确认后再计1分钟；记录保留原计划、实际和确认时间 |
| [ ] | 新增一条2分钟后的一次性自定义事项，填写标题和内容 | 指定时刻提示原文，确认后结束；直接重新开启被拦截，编辑未来时刻可重新安排 |
| [ ] | 普通事项即将到期时，开始1分钟会议 | 普通提醒在会议中不弹出；结束后有30秒收尾，再展示待办；不误记为完成 |
| [ ] | 暂停普通提醒1分钟，等待自动恢复 | 到期恢复；普通间隔重新计时，固定与一次性计划保留原时刻 |
| [ ] | 改变主题但不保存，切换通用/外观，取消 | 本窗口预览，草稿跨页保留；取消同时恢复通用偏好及原主题 |
| [ ] | 修改记录筛选日期但不应用，从托盘返回或关闭一次提醒预览 | 输入保留；应用前仍显示上次结果；无效日期就地解释 |
| [ ] | 保存主题和偏好，退出应用，再重新打开 | 计划、记录、更正原因和已保存设置保留；已完成的一次性事项不重复提示 |
| [ ] | 在方便的测试时段锁屏，跨过普通事项时刻后解锁 | 保留待办，缺少确认不会自动记成完成；记录恢复时刻和实际表现 |
| [ ] | 在方便的测试时段睡眠，跨过测试事项时刻再恢复 | 原有记录保留，恢复后继续调度；记录遗漏、重复或异常窗口 |
| [ ] | 实际会议/投屏中使用会议静音 | 检查真实共享画面及系统通知是否符合设置；单独记录共享软件及共享范围 |
| [ ] | 有多屏设备时切换覆盖范围，并在不同DPI屏幕上打开表单 | 提醒和紧急退出可到达；控件、日期弹层、固定操作区不越界 |
| [ ] | 调整Windows文字大小后走查输入、日期、记录与设置 | 标签和输入可读，能滚动到内容，保存/取消可操作 |
| [ ] | 全屏服药示例中查阅执行记录，再返回处理 | 历史与当前提醒均可到达，无窗口遮挡导致无法继续的情况 |
| [ ] | 持续一个工作日使用 | 记录漏提醒、重复提醒、计时偏移、意外退出和资源持续增长情况 |

记录问题时注明：版本、事项类型、循环规则、提醒方式、原计划时间、实际出现时间、是否开会/暂停/锁屏/睡眠、显示器及缩放；附截图或可重复步骤。不要把“没有点确认”当成已经完成。
