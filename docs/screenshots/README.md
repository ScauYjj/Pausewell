- `one-time-reminder.png`：一次性的取快递事项及自定义内容。
- `meeting-mode.png`：会议时长与提醒处理选项。
- `history.png`：虚构的执行与确认记录。
- `appearance.png`：五种主题与外观预览。

主界面的时钟、日期和倒计时以软件截图当时的实际显示为准，不代表用户所在地日期或真实健康记录。
