# 产品截图

这些图片截取自实际运行窗口，不是效果图。`home.png`、`activity-resume.png`、`delete-reminder.png` 与 `row-actions.png` 来自 v0.4.0，其余来自 v0.3.10。截图使用专门创建的虚构计划和记录，未读取或复制真实用户数据库。

- `home.png`：v0.4.0 返回后的提醒整理与事项概览。
- `activity-resume.png`：活动中断后的进度与处理选项。
- `delete-reminder.png`：删除事项的确认提示。
- `row-actions.png`：列表行操作的真实截图局部，展示删除悬停状态。
- `water-reminder.png`：软件自带的喝水提醒预览。
- `medication-plan.png`：示例药物的明确时刻与日期设置。
- `one-time-reminder.png`：一次性的取快递事项及自定义内容。
- `meeting-mode.png`：会议时长与提醒处理选项。
- `history.png`：虚构的执行与确认记录。
- `appearance.png`：五种主题与外观预览。

主界面的时钟、日期和倒计时以软件截图当时的实际显示为准，不代表用户所在地日期或真实健康记录。
