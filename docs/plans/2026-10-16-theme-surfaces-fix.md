# 整体换肤修复

用户已确认五种主题，现有问题是仅按钮、开关等强调色变化，整体仍残留暖香槟。此次修复在既有主题范围内推进，不重新选择风格。

1. 保留默认主题基础控件参数，为其他主题生成对应阅读表面、边框、焦点、悬停和选区色。
2. 移除环境背景与玻璃材质中固定的暖色，环境光、层面、阴影随所选主题计算。
3. 统一主窗口、表单和原有提醒窗口的主题来源。预览仅主窗口，保存才全局通知；原有窗口原地更新，保留草稿和计时。
4. 用真实场景渲染像素、五主题截图、取消恢复、跨页恢复、已打开表单与提醒验证。运行已有规则和完整 GUI 回归，独立发布 v0.3.5，不覆盖 v0.3.4 和现有数据。

不改变提醒规则和记录，也不把此次换肤修复视为全产品视觉验收。
