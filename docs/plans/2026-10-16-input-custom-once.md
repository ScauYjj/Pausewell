# 输入可读性、自定义及一次性提醒

本轮依据用户走查修复文字选中和自定义入口，并根据后续要求加入普通事项的“仅一次”频次。保持既有五种主题和药物独立规则，沿 Code 流程实施、验证和交付。

- 文字选区显式绑定背景、文字及光标颜色，五主题测量文字对比度并检查真实选中截图。
- 自定义显示提醒标题和内容输入，保留草稿，不覆盖已输入的名称。自定义标题和内容沿用现有 Name/Note 存储，实际提醒与记录使用相同内容。
- 普通提醒频次直接可选完成后间隔、每天固定时刻、仅一次。仅一次填写日期和 HH:mm，显示应用时区，不继承工作日时段。到期仅生成一项；延期沿用身份；明确结束后自动停用。会议/暂停和重启保留待办。
- 数据新增 OnceAt 与 Once 频次，schema 3；读取旧 schema 前备份，旧包不能回读新版本数据。本轮只使用新建隔离目录验证。
- 发布独立 v0.3.6，补充计划持久化、重启、实际提醒与核心回归。项目仍为功能集成试用与体验修正阶段，视觉和正式发布验收未完成。
