# 原生组件样板 Implementation Plan

**Goal:** 按已暂定的 v0.3.1 规范交付独立可运行的 Windows 组件样板，真实验证输入、下拉、日期、滚动和键盘焦点，供后续页面接入评审。

**Architecture:** 新建独立 WPF 控件资源项目与组件样板程序。保留原生控件及自动化能力，通过模板与少量日期/校验适配实现规范。样板不引用提醒业务和 SQLite，不覆盖 v0.2 包。

**Tech Stack:** .NET 10、WPF、版本化 JSON tokens、Microsoft Fluent SVG、原生 UI Automation 和窗口截图。

## 1. 规范状态与共享资源

记录用户已暂定 v0.3.1，保留参数在原生打样中可修正的范围。新增 `src/Pausewell.Controls`，读取现有 tokens 和图标，提供语义颜色、字体、尺寸、焦点与字段状态。

## 2. 完整原生模板

新增按钮、输入、多行、下拉及选项、复选/单选/展开、滚动容器与细滚动条。日期保留 DatePicker、DatePickerTextBox、Calendar、CalendarItem 与日期/月份按钮的部件、解析、选择和键盘能力，补固定格式与错误提示。

验证：先编译，再由真实窗口检查闭合/展开、三种日历视图、非法输入与五种主题；发现问题后复测受影响状态。

## 3. 独立样板程序

新增 `design/component-lab`，提供普通表单、日期与下拉、状态与滚动三个页面，含禁用、只读、错误、长文、无选项、日期范围、今日/选中/不可选以及记录分组。保存只修改内存，并清楚显示结果，不配置真实提醒。

## 4. 验收与交付

实现隔离自动化入口，检查真实 Popup、选择、日期输入/闰年/范围、复选和展开、滚动/焦点及保存语义。以外部 UI Automation 补键盘和控件模式验证；截图与静态规范同状态对照，记录通过与剩余验证缺口。

单独发布 `artifacts/Pausewell-component-lab`，提供根目录启动入口，打开样板供评审。更新计划与报告，区分组件已打样、材质未验收、正式页面未接入。正常应用和提醒数据不改动。

## 执行结果

- [x] 第一轮原生控件模板与三页独立样板。
- [x] 自包含发布包，实际包 52 项检查及 7 项外部 UIA 检查通过。
- [x] 真实截图和日历同状态对照、独立组件检查记录。
