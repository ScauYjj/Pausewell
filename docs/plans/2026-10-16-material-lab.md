# 材质与光影原生样板 Implementation Plan

**Goal:** 将用户确认的 v0.3.1 组件用于独立原生材质样板，验证全窗口暖色环境、导航、阅读卡片和任务浮层的层次，交付可交互程序和真实对照证据。

**Architecture:** 保留 WPF，新增与业务无关的材质实验项目。L0 为完整可缩放矢量环境；L1 为稳定阅读面；L2/L3 通过对下层独立视觉树的对应区域采样、仅背景模糊、白色叠层、定向高光和双层阴影构成。弹窗在样板内预览，不触发真实提醒。复用已确认控件，不修改旧包或数据库。

**Tech Stack:** .NET 10 WPF、VisualBrush、BlurEffect、已有语义 tokens、原生窗口截图和 UI Automation。

## 已定方案与替代项

应用内背景采样方案可复用现有 WPF，能验证环境变化、透射和层次，采用此方案。仅白色半透明覆盖无法充分表现环境传递，不继续作为主方案。迁移 WinUI/Acrylic 会扩大本阶段范围，且不等同于 Apple 的光学折射，暂不迁移。

## 1. 材质基础

新增 `design/material-lab` 项目，复用 `Pausewell.Controls`。新增矢量环境背景、独立的 GlassSurface、材质参数解析。明确 L1/L2/L3 各自 tint、blur、阴影和边界，文字所在层不带模糊。

验证：采样坐标与窗口布局一致，无循环视觉引用；背景变化确实传递到浮层；缩放/紧凑状态不截断主操作。

## 2. 可交互样板

提供三种环境、五主题、环境光位置调节、减少透明度和失焦模拟；组合导航、下次提醒卡、三行列表和模态提醒预览。预览的确认/延期仅改变样板状态，不写记录。模态期间背景不能操作，关闭后恢复焦点。设置和状态均明确标注样板含义。

## 3. 降级与验证

读取本机高对比度、UIEffects 与渲染等级，提供实色降级。减少透明度是样板手动开关，不宣称自动读取 Windows 同名设置。正常/明亮/对比背景、任务弹层、五主题、降级、失焦和紧凑窗口生成截图。测量实际合成色对比度，记录渲染等级和分配，不将短时测量等同长期性能验收。

## 4. 发布与评审

自包含发布 `artifacts/Pausewell-material-lab`，根目录 `体验材质光影.cmd` 启动。对照原选图和真实原生样板，记录已改善、仍有差异和未验证项目。用户确认的组件样板结论记录到文档；材质仍等待本轮体验评审，正式三基准页面接入在材质确认之后。
