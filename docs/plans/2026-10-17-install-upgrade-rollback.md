# v0.3.10 安装、升级与回退

主程序保持已验证的 v0.3.10，单独交付安装工具，不改调度和界面。

1. 发布 ZIP，含一键安装、卸载、程序回退及独立数据维护工具。使用本机 .NET SDK 构建，不依赖安装电脑上的 .NET。
2. 每用户安装到 LocalAppData/Programs/Pausewell；数据库沿用 LocalAppData/PausewellPrototype。安装路径必须与数据目录分离。
3. 修改前检查包哈希、已知版本、数据 schema、磁盘空间和同数据目录运行互斥锁。升级先生成 SQLite 一致性快照并保留旧程序；安装日志不包含提醒正文。
4. 程序回退只允许包清单内且支持 schema 3 的程序，保留最新数据库；数据恢复必须单独明确确认，并先备份恢复前的数据库。卸载默认保留数据、备份和回退程序。
5. 使用全新工作区目录验证首次安装、重复安装、v0.3.9 升级、程序回退、数据恢复、坏包/未知 schema/运行中拒绝、卸载保留数据。隔离模式不写启动项、快捷方式或卸载注册表。

安装成功不代表正式发布。签名、标准安装向导、真实锁屏/睡眠/多屏和全天试用继续列为待验收。
