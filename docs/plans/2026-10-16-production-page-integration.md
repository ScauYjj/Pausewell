# 基准页面正式代码接入 Implementation Plan

**Goal:** 将三个基准页接入现有桌面应用代码，保留调度、SQLite、托盘、记录、设置和提醒流程，发布独立 v0.3.4 试用包。

**Architecture:** 从页面样板提取 `Pausewell.Presentation`，用 IPlanContext 隔离时钟和业务引擎。正式上下文读取真实 UTC 时间与现有 ReminderEngine，样板固定时钟不进入正式程序。主窗口使用全窗口环境、导航材质和稳定阅读层；两类编辑通过现有控制器保存。原生产发布目录和用户数据库不覆盖，先用独立数据运行。

**Tech Stack:** .NET 10 WPF、共享控件、共享材质、现有 Core/Storage、原生 UI Automation 与真实时钟回归。

## 1. 提取复用层

新增 `src/Pausewell.Presentation`，迁入 PageUi、PlanForm、TimeFields、PlanDatePicker，改用 IPlanContext、真实可注入时钟与默认办公时段。正式程序集不得引用 PreviewSession、固定演示时间或页面样板程序集。

## 2. 连接正式应用

替换 PlanEditor 为共享表单适配，保留调用入口；增加正确的停用、会议与暂停保存提示。主窗口替换材质壳、字段/导航资源、列表和空态，修正全部停用标题、移除重复服药数量条。主题预览保持局部，保存才发布全局并持久化；取消恢复原色。

## 3. 验证与隔离

运行核心规则、正式 GUI 回归以及新增的表单取消/错误/草稿等接入检查。验证真实时钟到期、完成记录、重开恢复、主题、会议/暂停、队列、记录更正和数据库完整性。回归只使用新建独立目录与测试快照，不操作当前真实数据。

## 4. 发布与交付

独立发布 `artifacts/Pausewell-ui-v034`，提供使用独立演示数据的体验入口。记录测试结果、原生截图和未完成的光学/设备验收。正式代码已接入不等同已经迁移用户数据，整套视觉门槛继续单独记录。

## 完成记录

共享展示层与真实控制器已连接，独立发布 v0.3.4。补充了失败回退、时区边界、未保存修改和主题局部预览检查，以及发布 EXE 的外部 UIA 退出重开验证。证据与未完成范围见 `docs/design/2026-10-16-v0.3.4正式接入验证报告.md`。

后续工作：会议/暂停和实际提醒窗口的视觉统一，其次记录/详情与设置，随后跨页面和设备走查。整体视觉结论继续 blocked，不以功能通过代替视觉验收。
