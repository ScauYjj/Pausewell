# 轻透桌面界面与主题集成 Implementation Plan

**Goal:** 将已评审交互与暖香槟、灰紫、陶土橙、雾玫瑰、雾蓝五套外观落实为可运行的 Windows v0.2，并提供独立数据验收包。

**Architecture:** 沿用 WPF + Core 调度规则 + SQLite 事务快照。业务规则集中在 Core；桌面层处理导航、表单、窗口与主题资源。旧数据库先备份再升级，正式数据不用于测试。原发布目录保留，新版本发布到独立目录。

**Tech Stack:** .NET 10、WPF、Windows 原生 SQLite，原生窗口和 UI Automation 验证。

**2026-10-16 执行状态：** 下面五项已完成本轮集成与验证。规则 40 项及发布包 GUI 流程 40 项通过；外部 UI Automation 验证主题在真实进程重启后沿用。独立演示已打开，旧程序和旧数据保留。具体证据、材质差异与尚未覆盖的设备验证见 `docs/2026-10-16-v0.2集成验证报告.md` 及根目录 `design-qa.md`，不代表全项目发布验收完成。

## 1. 补齐业务规则

修改 `src/Pausewell.Core/Models.cs`、`ReminderEngine.cs`，新增业务扩展文件。覆盖有期限的普通暂停、可选服药静音、计划起止日期、独立启停、真实执行时间、更正原因与原值、主题持久化。对 schema 1 数据执行非破坏升级，不重新生成既有计划。

在 `tests/Pausewell.Specs/Program.cs` 添加行为测试：暂停不停止药物、恢复后重新计算普通间隔、药物时间不平移、日期边界、更正不移动未来计划、保存失败不发布候选状态、换肤不改变调度、旧数据兼容。

命令：`.tools/dotnet/dotnet.exe run --project tests/Pausewell.Specs -c Release -- artifacts/ui-v02/rules.json`。要求所有既有与新增检查通过。

## 2. 主题和主界面

新增桌面主题资源与共享控件，替换 `MainWindow.xaml` 及其后台：顶部提醒/服药/记录/设置导航，明确运行状态、下一次与当前待办，普通列表与服药分开，首次引导，有期限的会议/暂停窗口。默认石墨黑主按钮、暖香槟开关，保留原稿暖色透光及层次。

采用当前选定图 `design/ui/轻透主题/01-暖香槟-默认.png` 为视觉依据，主题变更保留结构与材质。外观设置只在本窗口预览，保存后全局应用；取消回滚，重开恢复。

## 3. 编辑与提醒流程

改造 `PlanEditor.cs`，普通事项展示必要字段，更多选项折叠；药物使用独立明确时刻与起止日期。首次不提前报错，间隔只预览首次具体时间，保存文案说明会议/暂停状态。

改造 `ReminderWindow.cs`：喝水、活动、如厕、药物各自明确动作，药物二次确认实际时间，不确定保留待核实；延期和关闭不计完成。长按紧急退出保留。会议后清单逐项处理，记录详情允许带原因更正。

## 4. 集成与保存

修改 `App.xaml.cs`、`DesktopController.cs`：设置一次后打开自动恢复，窗口关闭/托盘区分，会议期间药物隐私轻提示，旧数据备份，新增设置应用。保留正常与独立验收数据目录隔离。

## 5. 验收与交付

更新 `SmokeVerification.cs`，检查真实控件创建/编辑、主题保存和取消、活动计时、药物确认、更正、会议恢复、一次真实时钟到期与 SQLite 重开。截图对比原视觉目标，在常规和紧凑窗口检查裁切。必要时修正后重跑受影响检查。

发布到 `artifacts/Pausewell-ui-v02`，提供正常启动与独立演示入口；保留旧 `artifacts/Pausewell-win-x64`。使用新建独立演示数据打开新界面供用户体验。报告区分已验证与需要真实设备试用的项目，不把本轮交付称为全项目完成。
