# ADR-001：本地 Windows 技术验证架构

状态：阶段一采用，正式产品架构仍需依据试用结果调整。

## 背景

用户确认 Windows 优先。当前目标是验证循环规则、提醒窗口和会议恢复，尚不需要多设备账号与云同步。

## 决定

使用 .NET 10 与 WPF，规则核心独立于界面。持久化通过 Windows 自带 SQLite 完成，使用事务保存版本化状态快照。界面计时仅服务活动引导和长按交互，计划调度由应用服务驱动。

首版关闭后台提醒，药物示例停用；启动、解锁和睡眠恢复发现错过的药物时刻进入待核实。修改药物计划也保留原未核实事项。

会议中的药物仅更新托盘状态，避免通知气泡可能带来的系统声音；会议结束后恢复普通呈现。这意味着会议期间提示显著性较弱，是本阶段明确的取舍。

## 后果

无需云服务、第三方 NuGet 库或管理员安装。自包含发布带有运行时，包体较大；这是便于当前直接运行的取舍，并非包体优化结果。

状态快照简化事务与失败回滚验证，但数据规模扩大前应迁移为分表结构。当前普通间隔仍基于时间戳，运行时单调时钟校正属于后续可靠性工作；不能据现有固定时刻回拨测试宣称所有改时场景通过。

WPF 将界面绑定 Windows。跨平台时可保留规则核心，并重新选择和验证界面与系统适配层。
