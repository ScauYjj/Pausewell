# ADR-002：v0.2 桌面集成与数据兼容

日期：2026-10-16。状态：本轮采用，替代 ADR-001 中首次默认暂停、仅托盘状态提示等已调整行为。

继续采用 WPF、独立业务核心与 SQLite 事务快照，不引入服务器、账号或云服务。设置、计划、事项与更正历史一起原子保存。首次保存启用计划与启动调度在同一事务中完成，避免计划保存后启动失败却显示完全未保存。

schema 1 由程序读取前使用 SQLite VACUUM INTO 一致性备份，再兼容升级至 schema 2，新增字段保留默认值，不编造历史实际时间。旧版不能读取新 schema，发布包与旧版隔离，正常切换需先退出旧进程。测试使用独立数据和合成旧版快照。

全局运行与普通暂停分开。普通暂停有期限，默认继续药物提示；同时暂停药物后恢复缺少确认的事项进入待核实。会议默认药物轻提示，完全静音需明确选择。药物安排不平移，记录修改保留原值、原确认时间及原因。

主题以语义资源组织，默认主按钮与开关是两个独立颜色角色。预览仅覆盖当前设置窗口资源，保存后发布至应用资源并持久化；取消恢复。提醒窗口持有自身活动计时和事项身份，换肤不重建窗口。

采用原生 Windows 窗口与授权图稿纹理表达层次，不宣称拥有 Apple 原生 Liquid Glass 的实时光学行为。标准图标使用 Microsoft Fluent System Icons 并随包提供 MIT 许可证。

后续独立处理：更大历史量的分表迁移、单调时钟校正、真实设备的锁屏/休眠/共享/DPI/多屏测试、长期稳定性、安装签名与自动更新。
