日期：2026-10-16。状态：用户已暂定本版规范，进入原生打样。独立组件样板已完成首轮验证，结果见《原生组件样板验证报告》；正式软件仍为 v0.2，组件尚未接入正式页面，整体视觉验收仍为 blocked。

## 1. 判断与修订范围

需要更新。现有 v0.3 写了“统一高度、圆角和七种状态”，但还不够指导完整组件的设计、实现和验收。下拉项与弹层、日历内部、滚动条、复选框、展开按钮和焦点输入方式都缺少具体契约，样张也只有普通输入与按钮。与此同时，已有的输入统一规则尚未接入程序，不能全部归因于规范缺失。

本轮继续采用用户选定的轻透暖香槟，不重新换设计风格。玻璃用于导航、容器与浮层；录入面使用清晰稳定的浅色表面、统一细边界、同一图标体系和状态反馈，形成配套关系。组件无需各自成为强烈透明的装饰玻璃。

本轮新增：完整组件清单、闭合与展开态、键盘焦点、内部子控件、状态组合、字体/选区、滚动规则、页面组合方式和“完成定义”。所有参数为项目草案值，不是操作系统或 Apple 的官方参数。

## 3. 一套外观，需要覆盖整个控件树

WPF 可以通过 ControlTemplate 重新定义已有控件的外观，组件样式需覆盖整个模板和它的子部件。只修改 Background、Padding 或外层 Border 不足以得到统一形态。[Microsoft：样式与模板](https://learn.microsoft.com/en-us/dotnet/desktop/wpf/controls/styles-templates-overview)

| PwNumberField / PwTimeField | TextBox + 字段组合 | 单位槽、格式、粘贴、选择和校验 |
| PwTextArea | 多行 TextBox | 顶部对齐、字数、自动增长、内部滚动 |
| PwSelect / PwSelectItem | ComboBox / ComboBoxItem | 闭合面、箭头、Popup、选项、滚动、空列表 |
| PwDatePicker | DatePicker / DatePickerTextBox | 外框、输入、日期图标、Popup、格式与错误 |
| PwCalendar / PwCalendarDay | Calendar 等 | 月份头、翻月、周标题、日期格、月份/年份视图 |
| PwDateRange | 两个日期组件 + 范围校验 | 标签、基线、分行、起止关联、组级错误 |
| PwCheckBox / PwRadioButton | CheckBox / RadioButton | 选中图形、命中区域、标签、键盘焦点 |

## 4. 共同尺寸、字体和材质

闭合输入类组件基准最小高 40，圆角 10，边框 1，水平内边距 12，正文 14/22。40 是正常文字尺度的基准，不是强制锁死高度；放大文字时允许组件随内容增高。输入、下拉、日期、时间框在同一行时共用 MinHeight 与基线。

输入面 #FCFBF8，必要边界 #8D877D；卡片装饰线可用 #D9D5CD。悬停用 #F2EEE6，不做灰色拟物渐变。浮层外壳可使用 L2 材质和 E2 阴影，选项/日历内容保持稳定阅读面；文字和日期格不加模糊。

字体资源同时作用于 TextBox、ComboBoxItem、DatePickerTextBox、Calendar 按钮、CheckBox 标签和弹层，不只设置 Window。截图中不同文字有字体质感差异，但截图不足以确认具体回退字体，需在样板读取实际 FontFamily 与值来源后记录。

五主题共用尺寸与行为，主题替换 Toggle、Soft、Primary 和环境色。错误、禁用、文字、焦点语义保持稳定。高对比度模式改用系统颜色，不强制覆盖系统选区。

## 5. 状态组合与键盘焦点

各组件至少区分四组独立状态：交互（默认/悬停/按下/禁用）、焦点（无/输入激活/键盘可见焦点）、数值（空/已填/只读）、校验（有效/错误）。选择型组件额外区分已选与展开。不能把这些状态压成同一个 Focus 色块。

| 情境 | 表现 |
|---|---|
| 鼠标点击导航项 | 保留选中面，不额外出现黑色虚线框 |
| Tab 到达导航项 | 同一选中/未选基础上叠加可见焦点环 |
| 输入框鼠标激活 | 边界使用焦点语义色，边框仍是 1；显示光标 |
| 输入框键盘到达 | 激活态上叠加外侧 2 DIP 焦点环，间隔 2 |
| 已选 + 键盘焦点 | 选择面与焦点环同时可区分 |
| 错误 + 焦点 | 错误边界和说明保留，外部焦点环仍可见 |
| 禁用 | 无悬停/按下，数值和说明仍可读；不偷偷清空 |
| 只读 | 可阅读、复制、选择；样式与禁用区分 |

焦点环在 Adorner/覆盖层绘制，不改变 DesiredSize；选择态、Hover 和按下也不能使组件跳动。替换默认虚线的前提是提供统一可见的键盘焦点。WPF FocusVisualStyle 专门服务于键盘焦点，普通 Focus 属性又可被其他输入方式触发，应分别设计。[Microsoft：FocusVisualStyle](https://learn.microsoft.com/en-us/dotnet/desktop/wpf/advanced/styling-for-focus-in-controls-and-focusvisualstyle)

普通主题的文本选择使用 #DDD2BC 背景与 #292824 文字作为初始配色，避免只有日期/输入选区突然变成另一套蓝色。对应 API 与组合效果需原生验证；系统高对比度优先。

## 6. 文本、数字、时间和备注

单行文本全宽用于名称；时刻宽 128，数字加单位宽 176。宽度是常规布局建议，放大文字和长单位必须重新布局，不能横向裁切。分钟单位作为右侧稳定槽，不能让用户误以为还需输入“分钟”。

分钟允许 1 至 1440 的整数，活动时长允许 1 至 3600 秒，沿用现有业务规则。粘贴与直接输入适用同一校验，不只拦截键盘按键。时刻为 HH:mm，不引入大转盘或手机滚轮；非法时刻显示具体原因，不能自动把 25:70 改成某个有效时间。

备注使用同一输入外框，最小高 80、内边距 12、文字顶部对齐，正常尺度增长到 160 后内部滚动；可选并显示字数上限 1000。备注的内部滚动只在自身内容超限后出现，不能为两行文字常驻一条粗滚动条。外层表单仍可滚动，但需验证滚轮到边缘后的传递行为。

## 7. 下拉框与选项浮层

### 闭合态

高 40，圆角 10，文字距左 12；右侧图标槽 32，使用同一家族的 16 DIP 下箭头。文字不进入图标槽。只读选择型不显示文本插入光标，鼠标可点击整个闭合面。

### 展开态

- Popup 与字段间隔 6，左对齐，宽度至少与字段相同；超出工作区时调整位置或宽度，不越屏。
- 外壳圆角 12、内部留白 4、E2 阴影；最大高 320，常规先展示至多六项，再滚动。
- 选项基准高 40，左右内边距 12。已选项使用 Soft 底和 16 DIP 勾选图标；不能只改变文字颜色。Hover 是另一种浅底，已选 + Hover 仍保留勾选。
- 长选项允许两行并增高；不能把选项文字压缩得比字段更小。暂无选项时显示不可选择的解释行。
- 向上展开时视觉结构相同；失焦边界、Popup 内滚动条、禁用项和键盘焦点都使用本套样式。

键盘和提交：保留原生 ComboBox 的键盘选择、展开与关闭能力，并通过真实控件测试；Esc 只关闭当前弹层，不退出整个编辑窗口；Enter 确认当前选择时，不连带提交表单。不要为视觉改造擅自改变原生选择生效时机。编辑计划的业务保存仍由表单按钮触发。

模板需同时覆盖闭合外框、ToggleButton、Popup、ComboBoxItem、ItemsPresenter 和内部 ScrollViewer，不能仅把 ComboBox 外部包一层圆角。[Microsoft：ComboBox 模板](https://learn.microsoft.com/en-us/dotnet/desktop/wpf/controls/combobox-styles-and-templates)

## 8. 日期、日历和范围

### 日期闭合面

高 40，圆角 10，建议宽 208、最小 176，统一文本和图标槽。使用 20 DIP 标准线性日历图标，取消蓝色“15”日历小图。显示格式统一 yyyy-MM-dd；可以输入合法的斜杠格式并在有效提交后规范化，不悄悄修改非法内容。

格式、解析和错误适配都需要实现。不能仅设置系统 Short 格式后宣称所有机器都显示相同格式。空值显示“选择日期”，不把占位符保存为日期。只读、禁用、输入错误分别表达。

### 日历展开面

基准 304 × 384，内边距 12，圆角 16，E2 阴影。月份头高 40、周标题高 24；七列，每格占位 40、日期视觉面 32；保留六行避免翻月后高度突变。底部操作高 40，与日期区间隔 8。大字号时允许增大，不硬裁切进固定大小。

月头显示“2026 年 10 月”，翻月按钮命中 32、图标 16，标题可进入月份/年份层。周一为首列，中文周标题保持一致。月份、年份和年代视图也必须换肤，不能打开第二层后退回旧系统模板。

| 日期状态 | 视觉要求 |
|---|---|
| 普通 | Ink 数字，无多余外框 |
| 悬停 | 浅中性底 |
| 今天 | 日期下方独立短标记，并有说明；不等同于选中 |
| 已选 | Soft 底、Toggle 色边界、深色数字，不在浅香槟上放低对比白字 |
| 键盘焦点 | 叠加统一焦点环；已选状态保留 |
| 跨月可选日期 | 次级文字，仍可读；不能误做禁用 |
| 不可选日期 | 禁用样式、无点击行为；说明业务限制 |
| 已选 + 今天 | 保留选择面及“今天”标记 |

“今天”快捷入口仅在当前业务允许该日期时可用。“清除”只用于允许空值的字段。不能给必填开始日期提供一个会制造无效状态的快捷按钮。

DatePicker、内部 DatePickerTextBox、Popup、Calendar、CalendarItem、CalendarDayButton 和月份/年份按钮要整体设计，保留模板部件与日期校验能力。[Microsoft：DatePicker](https://learn.microsoft.com/en-us/dotnet/desktop/wpf/controls/datepicker)、[Calendar](https://learn.microsoft.com/en-us/dotnet/desktop/wpf/controls/calendar)

### 日期组合

- 药物开始/结束使用等高的 24 DIP 标签行，下面均间隔 8 后放同高字段。右侧标题行可放“设置结束日期”复选，不能挤歪字段基线。
- 不启用结束日期时，保留一致宽度的禁用字段与“不设结束日期”说明，不把开始字段上下拉动。
- 记录筛选的起止日期共用 PwDateRange，“至”在字段中线对齐；窄窗口整组分行，不拆散“至”和右侧日期。
- 起始晚于结束时，在组下给出错误，阻止无效保存/筛选提交。起始变化导致已有结束无效时保留输入并提示，不偷偷覆盖用户选择。

## 9. 复选、单选、次数和展开器

复选框视觉 18 × 18、圆角 4，标签距图形 8，整行最小命中高 32。勾选使用标准 12 DIP 勾选图标，选中背景使用有足够对比的主题 Toggle；Default、Hover、Checked、Indeterminate、Focus、Disabled 必须配套。复选用于是否启用、是否限定日期等组合条件，不能被样式强行改成即时执行开关。

互斥条件使用 RadioButton 或分段选择。次数选项统一高 36、间距 8，当前数量有 Soft 底、边界与明确选中标记；手工新增/删除时刻后同步数量表达，大于四次显示“自定义 N 次”，不能假装“4 次”仍被选中。数量只控制明确时刻的字段，不推算用药间隔。

Expander 标题行高 40，图标 16，图标到文字 8，整行可点击；使用标准线性箭头，去掉旧圆圈箭头。展开内容与标题间隔 12，字段组遵循 24 间距。Space/Enter 切换，标签同步“更多设置/收起设置”，屏幕阅读器能获得展开状态。

## 10. 滚动条与滚动容器

滚动采用 Auto，先解决不必要的内容溢出。只有内容超出可视区时出现滑块；不能靠把所有 ScrollBar 隐藏来掩盖布局问题。

轨道占位与命中宽 14，滑块视觉宽 6，Hover/拖动时宽 8；滑块最小长 32、两端圆角，使用 #827C72。静止时保留可发现的滑块，轨道透明；悬停时轨道 #EDE9E1，不显示上下箭头按钮。变宽发生在已预留区域内，不挤动正文。滚动条是桌面精细操作的特例，不套用普通按钮 32 宽的命中规则，同时保留滚轮和键盘替代路径。

保留拖动、轨道点击、滚轮、PageUp/PageDown、Home/End、焦点自动滚入视野及自动化能力。需要重新模板化 ScrollViewer、ScrollBar、Track 和 Thumb。程序当前 Auto 设置可以沿用，不能因为出现粗条就错误地把 Auto 改成 Hidden。[Microsoft：ScrollBar](https://learn.microsoft.com/en-us/dotnet/desktop/wpf/controls/scrollbar)

表单的标题与底部按钮固定，中间内容滚动。首页三条常用提醒在基准窗口可见；不要因为一个重复入口、额外 Margin 或小数裁切而产生无意义滚动。长表单和长记录列表出现滚动是正常状态，需要设计它的完整样式。

## 11. 记录列表与页面组合

记录页优先采用“一个日期分组容器 + 内部记录行 + 分隔线”，圆角只落在分组外壳，避免每行两道圆角边界。分组之间 24；行内留白 16、最小高 88，长时间说明自然换行增高；时间摘要用 14 号，操作区不被挤掉。

若将来采用独立卡片变体，外部间距 12 必须写在卡片最外层，禁止只写在内部 DockPanel。一个页面不能混用逐行卡片边框与同位置列表分隔线。

筛选区使用共用字段组件。宽屏一行对齐，窄屏按“事项/状态”和“日期范围”分两行，行距 16。日期组不能被剩余空间挤成不同高度。

首页全部停用时标题为“暂无已启用的提醒”，已保存列表继续可见；后台调度器保持运行与“正在运行的计划为 0”是不同信息，不都写成“提醒中”。

## 12. 设计交付和验收门槛

每种组件的交付包必须包含：组件结构、各状态图、展开图、组合态、尺寸/语义资源、键盘与鼠标行为、失败处理、缩放与降级。只有闭合态截图的 DatePicker 或 ComboBox 不能标为完成。

| 组件 | 本轮草案必须覆盖 | 原生实现后必须补验 |
|---|---|---|
| 输入/备注 | 空、已填、焦点、选区、错误、禁用、只读、长文 | 中文输入法、粘贴、复制、字数、滚动与读屏 |
| 下拉 | 关闭、展开、选中、Hover、焦点、禁用、空、长选项、向上展开 | 键盘、Esc/Enter 作用域、焦点返回、工作区与缩放 |
| 日期/日历 | 闭合、空、错误、禁用；今天/选中/焦点/跨月/不可选；月/年/年代 | 解析与非法值、月份切换、闰年、日期边界、弹层位置、自动化 |
| 复选/分段/展开 | 正常、选中、焦点、禁用、展开、混合态 | 整行点击、键盘、互斥、字段数量同步 |
| 导航 | 正常、选中、Hover、键盘焦点、选中+焦点 | 鼠标不残留旧虚线；Tab 可见且无布局位移 |
| 滚动 | 无溢出、溢出、Hover、拖动、低可视高度 | 滚轮/键盘、嵌套边界、焦点可见、缩放、自动化 |
| 记录/日期范围 | 多行、分组、长文、范围错误、窄屏 | 外间距、无双边框、时间不裁切、功能与现有规则一致 |

状态图不是行为测试；静态样张不证明 Popup、日期输入或滚动能力可用。材质参数也不等于已完成 Liquid Glass。规范评审、组件原生实现、页面接入和验收分别记录状态。

## 13. 实施顺序与版本关系

先做“普通编辑表单 + 下拉展开 + 日期日历 + 滚动”的隔离组件样板，同时做导航键盘焦点。它们与材质打样共同作为设计工作项，本轮不改运行程序。验证组件齐套后再统一页面，避免把设计细节留到全量开发之后。

本轮实物为规范修订、版本化 tokens、两张静态补充样张以及截图证据。完整组件状态矩阵列的是目标，不表示两张样张已经穷尽所有状态。原生交互、材质和全状态稿均保留待办。
