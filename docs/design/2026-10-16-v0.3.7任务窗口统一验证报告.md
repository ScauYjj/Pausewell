# v0.3.7 任务窗口统一

本轮按已确认的组件、五主题和材质规范完成会议、暂停、实际提醒、服药确认及会后待办清单的页面统一。当前仍是功能集成试用与体验修正阶段，整体视觉及正式发布验收尚未完成。

## 本轮变化

提取 `Pausewell.Presentation.MaterialWindow`：完整环境背景、任务玻璃表面、固定头尾与中部独立滚动采用同一套结构。主题保存时原地更新环境色、材质和表面，不重建输入或活动计时控件；低特效与高对比回退继续沿用共享材质逻辑。模糊只采样应用自己的背景，不作用于文字和表单内容。

| 窗口 | 本轮统一内容 |
| --- | --- |
| 会议及暂停 | 标题24、正文14及8/16/24间距；15/30/60/120分钟快捷填写；1至720分钟自定义；预计恢复时间随当前时间更新；影响范围明确；固定取消/应用与错误区 |
| 普通及活动提醒 | 移除旧拉伸纹理，使用完整场景和任务玻璃层；单项主操作、延期固定可见；说明过长时只滚动阅读区域；活动计时保持原控件 |
| 服药提醒及确认 | 未服用、待核实和已服用操作区分；统一药名及原时刻摘要、日期与HH:mm输入、未知实际时间、错误和固定保存区；次要按钮按统一间距排列 |
| 全屏提醒 | 统一完整环境与居中任务表面，保留长按紧急退出、普通关闭拦截及多屏遮罩机制；增加一次定位保护，避免重复加载创建多组遮罩 |

## 保持的业务规则

未修改 Core 和 Storage 的状态机。活动计时结束后仍等待明确确认；药物保存实际与确认时间，未知实际时间保留为空；延期不计完成；一次性提醒确认后不循环；会后清单不把待核实记录改为已服用。无效日期、HH:mm及未来实际服用时间在确认窗口就地拦截。

多项提醒继续逐项处理，完成一项时其余事项保留，全部完成后关闭。主窗口的会议及暂停仍只在点击应用后写入，取消不改变运行模式。数据库写入失败保留输入及范围选择，释放写锁后可原地重试。
