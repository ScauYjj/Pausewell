# v0.3.9 跨页面走查计划

沿用已确认的页面和交互规范，集中修复流程衔接，不扩展新功能或更换风格。

1. 提醒启停：让鼠标、键盘及辅助功能进入同一保存路径；失败恢复真实开关状态，拒绝重新开启已结束的一次性提醒。
2. 窗口返回：从托盘返回、关闭预览/提醒/清单，仅更新发生变化的数据，保留设置草稿和未应用的记录筛选输入。
3. 调度失败：数据库临时写入失败时明确显示调度暂缓，提供实际可操作的重试入口，成功后继续原计划，不靠重启或修改其他事项恢复。
4. 验证：复用既有核心与原生回归；补充失败恢复和窗口衔接专项。外部 UIA 从创建一次性自定义提醒开始，经过真实时钟到期、确认、记录、更正、会议、主题和进程重开完成一条连续流程。
5. 独立 v0.3.9 发布包与试用目录，核验旧包不变。真实锁屏/睡眠/投屏、多显示器、多DPI和长期办公试用单独保留待验收，不用模拟结果替代设备实测。
