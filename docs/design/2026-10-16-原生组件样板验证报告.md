# 原生组件样板 v0.3.1 验证报告

日期：2026-10-16。阶段：用户暂定规范后的第一轮原生组件打样。交付独立可执行程序和共享 WPF 控件资源，正式提醒程序保持 v0.2。

## 本轮结果

发布包构建零警告、零错误；实际发布程序的 52 项原生检查通过，另有 7 项外部 UI Automation 检查通过。结果只说明列出的组件路径在本机测试条件下有效，不等同于全产品完成或全部环境验收。

程序：`artifacts/Pausewell-component-lab/Pausewell.ComponentLab.exe`。入口：根目录 `体验原生组件.cmd`。源代码：`src/Pausewell.Controls`、`design/component-lab`。

| 范围 | 实现与验证 |
|---|---|
| 字段与按钮 | 输入、下拉为 40 DIP 基准，圆角 10；多行备注、禁用、只读、错误和独立键盘焦点；石墨主按钮保持白字。验证空名称、分钟 0/1441/小数、非法时刻和超长备注，错误提交保留输入。 |
| 下拉 | 真实原生 Popup，选中勾选、长选项换行、内部滚动、无选项说明。Esc 关闭弹层，Enter 完成选择，不连带提交外层。 |
| 日期 | 保留原生 DatePicker/Calendar，定制输入面与完整日历。阅读面 304 × 384 DIP，周一开头；支持日期、月份、年份视图，今日、选中、不可选和焦点区分。合法闰日归一为 yyyy-MM-dd，非法日期失焦仍保留原输入；范围错误不静默移动两个日期；可选结束日期可以清除。 |
| 其他状态 | 复选实际切换、展开与折叠、次数单选互斥；五主题切换保留字段值。次数控件仅展示互斥交互，不生成服药时刻。 |
| 滚动与导航 | 14 DIP 滚动命中区域和 6/8 DIP 滑块，无溢出隐藏；验证 UIA 滚动、PageDown、滚轮和真实滑块拖动。导航方向键切页并显示独立焦点，鼠标选择不套默认虚线框。 |
| 窗口 | 常规 1280 × 960 与紧凑 900 × 650 逻辑尺寸，内容超出可滚动，导航和保存按钮保留。系统工作区可能约束实际窗口大小，截图记录实际客户区。 |

## 证据与复现

- `artifacts/component-lab/release-verification/native-test-results.json`：实际发布包的 52 项检查、执行时间及 DPI。
- `artifacts/component-lab/external-uia-results.json`：独立 PowerShell UIA 客户端检查名称、ValuePattern、ExpandCollapse、Toggle、日期输入、ScrollPattern。
- `artifacts/component-lab/release-verification`：真实表单、错误、下拉、日历三视图、五主题、焦点和紧凑窗口截图。
- `artifacts/component-lab/calendar-comparison.png`：静态规范与真实原生日历，按 150% 截图归一到 304 × 384 DIP 比较。
- `artifacts/component-lab/release-manifest.json`：新包校验值及两个既有程序的校验值。

`scripts/build-component-lab.ps1` 发布自包含包并验证新包，失败返回非零。打开样板后可执行 `scripts/verify-component-lab-external.ps1` 复现外部检查，`scripts/compare-component-lab.ps1` 重建对照图。旧 run-01 至 run-08 为调试记录，以 release-verification 为发布依据。

真实截图由自己的原生窗口生成。透明 Popup 截图裁去 24 DIP 阴影边距，圆角外角可能出现黑色捕获底色，因此截图只用于阅读面、状态和尺寸对照，不用于确认阴影或玻璃光学效果。左侧静态日历另含 21 日悬停和说明文案，右侧未模拟这一鼠标位置。

## 隔离与限制

样板不引用业务核心和数据库项目；保存仅在内存，重启重置。没有建立提醒计划、变更自动启动或改写正式数据。两个旧发布 EXE 的 SHA256 与本轮前一致。

本机测试为 144 DPI，即 150% 缩放。尚未完成其他 DPI、多屏切换、系统文字放大、完整中文输入法与文本选区、屏幕阅读器、高对比度及减少透明度设置验证。当前共享滚动模板面向纵向场景，不能宣称已覆盖通用横向滚动。此次没有验证长期运行稳定性。

组件样板尚未接入真实业务页面，真实业务绑定、记录分组和超过四次时刻编辑仍需页面阶段验证。Liquid Glass 材质、光影、正式页面排版与整套应用视觉验收仍未完成，根目录 `design-qa.md` 保持 blocked。下一工程阶段为局部材质打样，再形成首页、普通编辑、药物编辑三张基准页面。

保留 WPF 原生部件与自动化语义的依据：[Microsoft DatePicker](https://learn.microsoft.com/en-us/dotnet/desktop/wpf/controls/datepicker)、[Microsoft Calendar](https://learn.microsoft.com/en-us/dotnet/desktop/wpf/controls/calendar)。本报告的测试数量来自本地检查记录。
