# 材质与光影样板 v0.3.2 验证报告

日期：2026-10-16。前置：用户已确认 v0.3.1 原生组件样板。当前交付：独立可交互材质程序，材质效果等待用户体验评审；正式业务程序保持原版。

## 交付与工程结论

发布包为 `artifacts/Pausewell-material-lab/Pausewell.MaterialLab.exe`，根目录入口为 `体验材质光影.cmd`。构建零警告、零错误，实际自包含发布包的 39 项原生检查通过，另有 8 项外部 UI Automation 检查通过。检查范围仅限此样板，不代表整体视觉通过。

| 层次 | 本轮实现 |
|---|---|
| L0 环境 | 覆盖整个场景的完整矢量背景，不截取或拉伸原图。暖色、明亮、对比测试三种环境；环境光位置可调，五主题使用已确认的环境色。对比测试线条仅用于检查透射。 |
| L1 阅读 | 94% 白色稳定阅读面，E1 阴影；内部卡片和列表保持清楚，不给每行叠玻璃。 |
| L2 导航 | 对背景对应位置实时采样，24 DIP 背景模糊、定向高光、轻暗边与双层阴影；当前选中面和键盘焦点分别表达。 |
| L3 任务 | 对完整下层场景采样，28 DIP 背景模糊、E3 阴影，正文独立实色阅读面。提供首页弹层及隐藏阅读面的透射对照。 |
| 降级 | 手动减少透明度改为实色并移除模糊；模拟失焦提高稳定性并减弱阴影。系统高对比度、UIEffects 关闭及 Tier 0 进入实色路径，这些系统条件没有逐项更改设备设置来验证。 |

首轮原生对照发现 56% 导航白叠层、78% 任务白叠层与明亮环境组合后过于接近实色，因此本轮独立调校为 48% / 62%。参数保存在 `design/system/v0.3.2/material-tuning.json`；不修改已确认的 v0.3.1 组件尺寸、配色或样式。初始规范中的材质数值仍作为起点保留，不将本次调校冒充用户已经确认的最终参数。

## 验证证据

`artifacts/material-lab/release-verification/material-test-results.json` 记录实际包运行时间、144 DPI、WPF 渲染 Tier 2、39 项结果、截图区域和内存快照。

检查覆盖：无业务/数据库依赖；材料参数；采样坐标与 32 DIP 过采样边缘；视觉树无递归；文字树不加 BlurEffect；移动环境光改变导航实际像素；三环境和五主题；实色和失焦；弹窗初始焦点、Tab 循环、确认与延期、Esc 退出预览及焦点恢复；背景操作隔离；紧凑窗口主操作可见；静止 600 ms 未主动重绘环境或重设采样坐标。后一项不是 GPU 空闲功耗或帧率测试。

最终发布检查中，导航背景样本对正文色的最低对比度约 12.64:1，任务透射背景样本约 12.15:1。五主题主按钮白字均超过 4.5:1，最低为陶土橙约 4.94:1。背景样本来自实际合成截图，取控件内部无文字水平带；不代表整屏、全部位置、所有状态或完整 WCAG 验收。

`artifacts/material-lab/external-uia-results.json` 是独立客户端的 8 项结果，检查进程、滑块 RangeValuePattern、复选 TogglePattern、模态隔离、确认返回和透射对照返回。样板内允许 Esc 和返回，不改变正式提醒的退出规则。

截图以发布包 `release-verification` 为准。`01-reference-home-comparison.png` 比较原选图与暖色首页场景；`02-reference-task-comparison.png` 比较原图任务窗与原生透射样板。对照移除工具栏，保留宽高比，记录尺寸差异。第二张裁到任务面，阴影外部不在裁图内，应另看完整 `14-transmission-contrast.png`。

## 视觉判断与限制

已形成实际背景传递、模糊、定向边缘与分层阴影，工程上可以继续沿 WPF 推进应用内材质。仍有明确差距：原稿的复杂环境纹理、体积感、折射和图标周围光晕没有完整复现，不能宣称等同 Apple Liquid Glass。当前属于柔和磨砂玻璃方向，是否满足产品目标仍由本轮体验评审决定。首页只是材质组合场景，正式首页排版和两个编辑页面尚未接入。

短时重复切换及截图后的进程私有内存约 393 MiB、工作集约 464 MiB。这是单次样板运行末尾的快照，包含渲染资源和截图开销，不是空闲稳态、GPU 显存或长期泄漏结论。正式接入前仍需做内存、重绘成本和低性能设备评估，当前不能宣称性能达标。

仅验证本机 150% 缩放。多屏、其他 DPI、系统文字放大、完整屏幕阅读器、高对比度整套语义色和图标、系统减少透明度自动同步、低渲染等级与长时间运行尚未验收。手动减少透明度开关不读取 Windows 同名设置。没有持续动画定时器，环境光仅响应用户操作。

原生任务样板没有读取桌面像素，不透视其他窗口，也不采集屏幕内容；只采样自身下层视觉树。正常提醒、药物计划、数据库和旧发布包不改动，校验值见 `artifacts/material-lab/release-manifest.json`。
