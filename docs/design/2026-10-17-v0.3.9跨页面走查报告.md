# v0.3.9 跨页面走查

本轮沿用既有设计规范，集中处理跨页面行为，交付办公试用候选包。当前仍处于集成试用，未完成真实办公环境、长期稳定性、整套视觉和正式发布验收。

## 修复结果

| 触发路径 | 原问题 | 修正后的行为 |
| --- | --- | --- |
| 辅助功能切换提醒启用状态 | 开关改变，数据库未随操作写入 | Checked/Unchecked 统一保存；失败恢复实际状态；已结束的一次性事项拒绝直接重开 |
| 托盘返回、预览或提醒关闭、清单关闭 | 整页重建打断未应用的筛选与当前控件 | 按状态更新列表和时钟；设置、主题预览与筛选输入保留 |
| 原提醒尚在时进入待办清单 | 原窗口继续占据前面，妨碍查看清单 | 收起原提醒，保留待办状态，在清单内逐项处理 |
| 调度遇到数据库写入失败 | 调度停止，仅提示重新开始，缺少明确恢复入口 | 显示“提醒调度暂缓”和“重试调度”；写入仍失败时保留故障；解除占用后继续原计划，不自动记录完成 |
| 辅助功能修改会议/暂停范围 | 选择变化后说明未同步 | 状态和说明同步；应用时保留范围 |
| 独立试用中关闭托盘设置 | 页脚仍一律声称关闭后驻留托盘 | 页脚按实际关闭设置显示，与执行行为一致 |

本轮没有修改 Core/Storage 状态机及 schema 3。调度故障提示独立于一般表单错误，取消设置、清除表单错误或更改其他事项不会掩盖仍然存在的调度故障。重试使用原有真实调度入口。

## 验证路径

核心规则与原生 GUI 沿用既有回归，并增加跨页面专项。专项使用独立 SQLite 写锁制造真实调度失败，检查首次失败、仍被占用时重试、解除占用后恢复、完成后不重复生成及其他计划时间不变。通过真实辅助功能 Toggle 接口检查提醒启停与范围文案；通过窗口隐藏/恢复、预览和清单进出检查输入保留。

外部 UIA 在发布 EXE 的新建独立数据中执行一条连续流程：创建并启停普通提醒，保存主题和偏好，验证筛选错误及取消，创建自定义一次性事项，等待真实系统时钟到期，确认完成，查看记录并更正，检查已结束事项不能直接重启，实际应用/结束会议与暂停，然后退出应用并以新进程重开，核验计划、完成状态、修改历史和设置保留。没有直接向数据库插入这条外部流程的记录。

最终结果：51/51项核心规则、160/160项原生GUI检查、32/32项外部UIA连续流程检查通过；核验10个旧版包哈希未变。统计见 `artifacts/v039/release-manifest.json`；原始结果为 `rules-test-results.json`、`release-gui/gui-test-results.json` 和 `external-uia-results.json`。外部报告绑定 EXE 哈希及独立数据目录。原生专项截图90至92展示窗口返回、调度故障和恢复后的真实提醒，已打开复核。
