# v0.3.10 安装、升级与回退交付

这轮复用已验证的 v0.3.10 主程序，新增独立维护工具与可审查的一键安装包。安装包是 ZIP 加 Install.cmd，不是标准签名安装向导；尚未发布到外部网站。

## 使用入口

完整解压 `artifacts/install-v0310/Pausewell-0.3.10-win-x64-install.zip`，双击 `Install.cmd`，完成后从开始菜单打开“间歇 Pausewell”。无需管理员权限。两个程序均使用 self-contained 发布配置，不依赖目标电脑另装 .NET；本轮没有在干净虚拟机验证。

正常程序目录是 `%LOCALAPPDATA%/Programs/Pausewell`，正常数据库沿用 `%LOCALAPPDATA%/PausewellPrototype/pausewell.db`。程序和数据目录不能互相包含。安装不自动运行、不自动创建提醒，已有数据的开机启动设置会沿用；若启动项指向另一位置，则先拒绝安装，要求在原程序中关闭后重试。项目中各体验入口的独立 demo 数据不会被自动导入。

运行中的同数据目录实例或同安装目录程序会阻止维护操作。工具不会强行结束它们。普通安装会登记当前用户卸载入口和开始菜单快捷方式，开机启动仍以用户已有设置为准。

## 升级与程序回退

安装前检查所有清单文件 SHA-256、数据库完整性与 schema、目录归属和可用空间。现有受管安装只接受清单内的 v0.3.9、v0.3.10。旧项目的散装发布目录不会被直接覆盖，也不会自动卸载。哈希检查用于发现文件损坏，包尚未签名，不构成发布者身份认证。

升级先在数据目录 `backups/install-*` 生成 SQLite 一致性快照、旧主程序及程序清单，之后在程序所在磁盘暂存并校验新文件，再更换目录。数据库不随程序替换，不重算提醒，不改确认状态或更正历史。目录更换失败会尝试立即恢复旧目录，未做断电故障注入验收。

程序回退用安装包或安装目录中的脚本：

```powershell
.\Manage-Pausewell.ps1 -Action rollback -SourcePath "完整的 backups/install-* 备份目录"
```

回退仅替换清单允许的主程序，保留最新数据库。备份中的程序哈希和兼容版本都必须匹配。目前只支持同为 schema 3 的 v0.3.9 与 v0.3.10，不能据此推断未来版本可降级。回退之前同样保存当前程序和数据库。备份没有自动过期清理。

## 数据备份与恢复

```powershell
.\Manage-Pausewell.ps1 -Action backup
.\Manage-Pausewell.ps1 -Action restore -SourcePath "完整数据库备份路径" -ConfirmDataRestore
```

数据维护进程不实例化 ReminderEngine。读取使用 SQLite 只读连接，备份使用 SQLite backup API，包含已提交的 WAL 页面，拒绝覆盖已有备份。

恢复数据与回退程序是两个独立动作。数据恢复要求显式参数，恢复后看到的是所选快照时刻的记录，之后新增的记录不会出现在该视图中。替换前另存当前一致性快照，保留原主数据库和残留 WAL/SHM，放在 `backups/before-restore-*`；恢复工具不把未核实记录标为已完成。重新启动主程序时仍会执行既有的到期恢复规则。

维护工具接受 schema 1 至 3 的备份/完整性检查，拒绝未知版本。安装操作本身不迁移数据库；主程序首次打开 schema 1/2 时仍按既有规则先备份再迁移。本轮安装集成验证使用 schema 3 夹具，没有触碰真实使用数据，也没有宣称完成真实旧库迁移验收。

## 卸载与保留

可使用 Windows 应用设置中的卸载入口，或运行 `Manage-Pausewell.ps1 -Action uninstall`。默认保留数据、诊断和全部备份。只有指向此安装目录的 Pausewell 启动项会被清除；不同位置的启动项不删除。

程序文件按照安装清单逐个移除，发现不属于清单的文件就拒绝卸载，避免递归删除用户文件。没有“卸载同时清空健康记录”的默认选项。保留的数据可在重新安装后继续读取。

## 验证与边界

集成测试位于 `tests/Pausewell.Deployment.Specs`，从实际 ZIP 解压后执行 Windows PowerShell 5.1 安装脚本及 self-contained 维护 EXE。实际拉起已安装主程序，通过原生 UIA 的“设置 > 退出应用”正常退出，测试从不使用真实数据目录。结果位于 `artifacts/install-v0310/deployment-test-results.json`，与安装 ZIP 的哈希绑定。

隔离模式不写真实启动项、开始菜单或卸载注册表，测试比较操作前后的归属状态。当前用户的真实注册安装和 Windows 设置中的卸载入口尚未实际验收。标准安装向导、代码签名和自动更新尚未交付。真实锁屏、睡眠、多屏、多 DPI、全天办公试用以及整体视觉验收仍保持待验收，不因安装测试通过而转为正式发布。
