# v0.2 界面复审与整改清单

日期：2026-10-16。结论：功能集成可以继续使用，但材质、光影、空间层次尚未达到所选效果图，视觉验收需要重新整改。上次把主要材质差异列为 P3 的判断偏轻，本轮调整为 P1。

本轮使用新启动的隔离演示数据，通过 Windows UI Automation 导航和 PrintWindow 截取九个原生页面状态。没有保存计划、会议或设置，没有改动旧版和用户正在使用的演示数据。原始截图及时间/DPI 清单位于 `artifacts/design-v03/audit`。对照原稿沿用用户此前选择的默认主题图，当前实现证据全部为本轮新截取。

## 1. 效果图与当前实现

![本轮原稿与实现对照](D:/个人资料/Codex/RemiderAPP/artifacts/design-v03/audit/10-reference-comparison.png)

左：已选原稿，主窗口内容裁切 1004 × 820。右：本轮真实程序的客户区 1484 × 1243，144 DPI，保持宽高比缩放至 1004 宽。窗口设置为 1004 × 866 DIP。两者视口高度及原生边缘略有差异，因此不拿这些差异解释材质问题，也不做逐像素位置误差的虚假统计。真实时间与原稿时间不同。

### P1：全窗口材质关系消失

可见证据：原稿有暖色环境、内容面和悬浮控制的连续层次；当前只有顶部色条，正文大面积纯白，导航像普通白色胶囊。

代码核对：`Theme.cs` 把图稿 Viewbox (0.038,0.122,0.132,0.084) 的小片段 Stretch.Fill；`MainWindow.xaml` 的玻璃背景 Border 没有跨行，只在第一行，内容面为 `#FCFFFFFF`，约 98.8% 白。这样无法传递完整环境光。

整改：建立覆盖全窗口的应用自有 L0 背景，分开内容与控制材料；为导航、卡片和任务弹窗设置不同的高光、边缘、阴影及降级。禁止把细纹理拉伸和纯白阴影组合标为 Liquid Glass 完成。

### P2：页面和组件没有同一套尺度

可见证据：主页与会议、药物表单之间，标题、按钮位置、下拉框、日期框、圆角和留白明显不统一。表单保留系统灰色下拉样式，设置则是大量小复选框。

代码核对：主内容、表单、待办使用不同的 24/26/28/30 等容器边距，字号也按窗口独立填写。`Ui.Panel()` 只有一种实白卡片角色；按钮 Hover 整体降低透明度，焦点增加边框宽度，会影响文字清晰度和内部空间。

整改：用统一的尺度、语义资源、组件状态和页面骨架替换逐页拼接。先统一按钮、字段、开关、列表行、设置行、弹窗，不直接在每页加更多装饰。

### P2：首页空间分配与表单密度需要重新校准

可见证据：首页只有三条计划已经出现滚动，下面还有重复的服药数量条；普通表单不多的核心字段也依赖滚动；记录的空状态只是一条提示，缺少完整的页面组织。

整改：以三条普通提醒完整可见为首页基准；去掉重复数量大条；明确表单主体与固定操作区；记录、服药、设置各用共同的标题和内容栅格，按空/有内容状态分别设计。

### 步骤 7：外观，预览语义清楚，实际组件样板不足

### 步骤 8：喝水提醒预览，动作清楚，浮层层次未达目标

![步骤9 会议](D:/个人资料/Codex/RemiderAPP/artifacts/design-v03/audit/09-meeting.png)

## 3. 可访问性与证据边界

可见风险：文字在浅玻璃上需要实测对比，焦点不能只靠极细颜色变化，日期/下拉不能只依赖内部标签，重要时间和药名不应变成小字。此次截图只能支持可见风险判断，不能证明键盘、读屏或全部缩放已通过。

本轮为 144 DPI。PrintWindow 输出的抗锯齿和缩小后的字形不能用于认定某字体完全匹配，也不能替代高 DPI/文字放大专项验证。材质和组件结构的判断有截图和源码共同支持。

本轮没有实际到期、活动全流程、多条待办、药物确认、记录更正、系统菜单、减少透明度和真实桌面背景适应的完整证据。这些列入规范和后续验收清单，没有使用旧截图补作本轮已经检查的证明。

## 4. 整改顺序与交付

1. 设计规范与 tokens 形成草案；本轮已提供。
2. 原生材质样板：导航、提醒卡、任务弹窗，证明同场景下的光影和层次。
3. 基础组件库：按钮、字段、开关、列表行、设置行、弹窗及状态；本轮仅有规范和静态样张，尚未接入程序。
4. 首页和两类表单的高保真页面及关键状态，作为整套页面的基准。
5. 全页面采用同一规范，再逐页做视觉与行为双验收。

对应规范：`docs/design/2026-10-16-设计系统规范-v0.3.md`。功能检查结果仍保留，视觉验收结论单独记录；不能用现有功能通过来覆盖本轮视觉问题。
