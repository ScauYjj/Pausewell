# 三个基准页面样板 v0.3.3

这是独立的页面评审程序，使用已确认控件与现有材质参数。所有数据只在本次会话保存，关闭重开重置。固定演示时间为 2026-10-16 09:00，不运行后台调度，不触发提醒，不连接正式数据库。

双击项目根目录 `体验基准页面.cmd`，或运行发布包的 `Pausewell.PageLab.exe`。自包含 Windows x64 程序，无需管理员权限或另装 .NET。

运行 `Pausewell.PageLab.exe --empty` 可从没有任何计划的空态开始，体验第一次保存。

可体验的流程：

- 首页：三条普通事项、下一次提醒、启停、新增和编辑；会议/暂停按钮在本次会话模拟 30 分钟模式。
- 普通编辑：名称、事项、间隔、提醒方式；活动显示时长；更多设置里切换固定时刻、工作日和有效时段；保存后列表更新。
- 服药导航：提供进入药物编辑的列表。示例药物默认停用；新增不预填药名或服药时刻。
- 药物编辑：1/2/3/4 次或增加至 24 个时刻；减少次数暂存多余时刻，增加时恢复，保存只提交当前可见次数。起止日期、重复时刻和非法格式会被校验。
- 启用、取消、保存保持在固定操作区。修改后取消或关闭窗口会提示保留/放弃；保存失败保留输入。

药物时间由用户按已有安排填写，软件不按次数自动计算服药间隔。主页“记录”和“设置”在本阶段禁用，后续接入。保存的提醒只存在于样板内存，并不能用于日常提醒。

构建验证：`powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-page-lab.ps1`。脚本会打开自己的测试窗口并向样板发送键盘输入，测试完成后退出、恢复光标。测试时保持样板前台。

本轮没有完成整套产品、多设备、长期性能或原图光学效果验收。图标许可见 `Assets/LICENSE.txt`。基准页与验证证据见项目 `artifacts/page-lab`。
