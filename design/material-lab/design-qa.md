# 材质样板视觉检查

日期：2026-10-16。结果：工程样板可进入用户体验评审，整体视觉尚未通过。

已打开真实发布截图及原图并排对照，检查暖色首页、任务层、对比环境、实色和紧凑窗口。背景采样、模糊和阴影可交互，不使用整张 UI 图充当软件。首页时间为固定演示值，三个事项均启用，与原图内容状态接近。

本轮改善：全窗口有连续环境背景；导航具备独立透射和阴影；阅读层与任务层职责分开；调整过厚白叠层；紧凑任务动作区固定、主体滚动。原生组件仍使用已确认的资源。

尚未解除的视觉项：

- P1，原稿复杂纹理、体积、折射与光晕仍有差距；本轮是可运行的磨砂玻璃实现，不判等效复现。
- P2，首页组合场景的密度、时间列宽和比例尚未按正式基准页面完整校准；对照图以材质比较为主，不能据此宣布首页已验收。
- P3，当前原生边缘和图标的光学重量与生成稿不同，需要在正式页面阶段继续校正。

证据在 `artifacts/material-lab` 的两张 reference comparison 和 `release-verification` 的完整窗口截图。原图与样板窗口比例不同，比较按宽度归一并保持比例；工具栏已移出首页对照。任务局部图不包含外部阴影，完整图保留阴影证据。

原生检查和外部 UIA 通过仅适用于列出的路径。用户本轮尚未确认材质效果，根目录整体视觉门槛继续 blocked。
