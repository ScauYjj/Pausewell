# 间歇 · 材质与光影样板

这是组件确认后的独立材质评审程序，不是提醒业务的新版本。时间固定为演示值，确认、延期和启停只改变本窗口状态，不连接数据库。关闭即重置。

运行项目根目录 `体验材质光影.cmd` 或本包 `Pausewell.MaterialLab.exe`。自包含 Windows x64 程序，无需管理员权限或另装 .NET。

建议依次体验：

1. 保持暖色环境，观察全窗口背景、导航浮层、阅读区与卡片的层次。
2. 拖动“环境光位置”，确认导航背后的光线确实跟随背景变化。
3. 切换明亮和对比测试环境，检查边缘与文字可读性。对比环境的线条只用于检测透射，不是正式主题装饰。
4. 点击“预览提醒弹窗”，体验文字清晰度、阴影、确认和延期；Tab 在任务动作间循环，Esc 返回样板。这里允许退出预览，不代表正式强提醒可以直接退出。
5. 点击“材质透射对照”，暂时隐藏阅读面，观察同一任务层直接叠在环境背景上的材质。返回后恢复首页示例。
6. 勾选“减少透明度”和“模拟失焦”，比较降级及非活动状态。减少透明度为本样板手动开关，没有自动同步 Windows 同名设置。

三种环境、五种主题、所有交互仅服务于材质评审。导航按钮展示选中态，不承载完整服药/记录/设置页面。编辑、新增和会议流程尚未在此样板实现。

当前为应用内背景采样、局部模糊、白色叠层、定向高光与分层阴影，不是 Apple 的实时折射或桌面背景透视。高对比度、UIEffects 关闭和 WPF Tier 0 会触发实色路径，完整系统辅助功能仍需专项验证。

构建验证：`powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-material-lab.ps1`。验证会显示自己的窗口并发送仅限样板的键盘输入，结束后退出并恢复光标。不得把本次通过当作正式页面、全部 DPI 或长期性能验收。图标许可见 `Assets/LICENSE.txt`。
