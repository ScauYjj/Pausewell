# 独立组件样板视觉检查

日期：2026-10-16。结论：本轮已检查的组件阅读面和交互可进入用户体验评审。整体产品视觉门槛仍为 blocked。本文件不能代替根目录的完整应用检查。

对照基线为用户暂定的 v0.3.1 静态组件样张。实际证据为自包含发布包生成的原生截图，环境 144 DPI。日历对照按 1.5 倍归一，不把截图像素当作 DIP。组件展示页不是正式页面，整页布局不与产品效果图直接等比比较。

已打开检查：普通表单、下拉 Popup、日期月视图、年视图、年代视图、状态页、鼠标与键盘导航、紧凑窗口。对照 `artifacts/component-lab/calendar-comparison.png` 检查今日与选中叠加焦点、日期网格、边界及尺寸。输入和下拉等高、日历尺寸另有原生测量断言。

| 检查 | 结论 |
|---|---|
| 字段、图标、表面 | 原有直角输入、系统渐变下拉和旧日历图标已在独立样板中替换。输入面稳定可读，与暖色表面和同一套 Fluent 图标配套。 |
| 状态 | 勾选、只读、禁用、错误、键盘焦点与选中分别表达；不再依靠默认虚线框。 |
| 几何与溢出 | 输入/下拉 40 DIP，日历阅读面 304 × 384 DIP。紧凑时由内容区滚动，导航和保存可见。 |
| 差异 | P3：日历标题字距与箭头视觉重量仍与静态样张有差异；静态样张的底部提示文案没有复制到控件中。由页面说明承接，后续页面打样继续校准。 |
| 截图限制 | Popup 圆角外的黑色属于透明窗口捕获底色；截图已排除阴影边距，不能用于材质验收。 |

本轮已检查范围未发现阻止进入组件体验评审的 P0/P1/P2 问题。完整可访问性和全环境验证尚未完成；这些缺口保留在验证报告，不因当前自动化通过而关闭。
