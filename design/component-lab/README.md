# 原生组件样板 v0.3.1

这是独立的 Windows WPF 组件体验程序，不是新的提醒业务版本。保存只记录在内存，关闭重开会重置，不创建提醒，也不读取提醒数据库。正常运行不需要管理员权限或另装 .NET。

项目根目录双击 `体验原生组件.cmd`，或打开发布包中的 `Pausewell.ComponentLab.exe`。

- 普通表单：输入、备注、下拉、复选、展开和错误提示。将分钟填成 0 或时间填成 25:70 后保存，可检查错误保留。
- 下拉与日期：长选项内部滚动、无选项、日期输入和范围检查。点日历标题可在日期、月份和年份视图间切换；结束日期可选并支持清除。
- 状态与滚动：禁用、只读、错误、次数互斥、混合复选、细滚动条。试用 Tab、方向键、Space、Esc、PageDown 和滚轮。
- 右上角切换暖香槟、灰紫、陶土橙、雾玫瑰、雾蓝。普通表单主题切换保留当前输入。

构建验证：项目根目录执行 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-component-lab.ps1`。脚本会打开独立测试窗口并发送仅限样板窗口的键盘和鼠标输入；测试时保持窗口前台，结束后退出并恢复光标位置。

材质、完整业务页面和所有设备环境尚未验收。样板目前仅验证 150% 缩放；完整中文输入法、屏幕阅读器、系统高对比度、文字放大及其他缩放仍待验证。次数选项用于检查互斥控件，不会生成服药计划。许可见 `Assets/LICENSE.txt`。
