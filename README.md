# 间歇 Pausewell · v0.3.10 办公 Beta

版本管理从 `v0.3.10-beta` 建立源码基线。版本范围见 `CHANGELOG.md`，分支、构建和发布约定见 `CONTRIBUTING.md`。`artifacts`、数据库、日志和工具缓存不提交；克隆后先按说明构建，不会自动包含本机旧包或个人试用记录。

当前进入基本功能冻结后的办公 Beta。双击 **`开始办公试用.cmd`**，优先使用已安装且哈希一致的 v0.3.10，数据独立保存在 `%LOCALAPPDATA%/PausewellOfficeTrial-v0310`。首次为空白，需要自行创建提醒，之后从同一入口打开会恢复计划。普通安装和现有正常数据库保持原样。

试用后双击 **`收集办公试用结果.cmd`**，生成仅含运行汇总的本地报告，可在“办公试用记录.md”补充实际问题。不会导出数据库、原始日志、事项名称、药名或备注，也不自动发送。详细步骤见 `docs/testing/2026-10-17-Beta办公试用.md`，本轮工程证据见 `artifacts/office-beta0310/verification.json`。真实办公、锁屏、睡眠、多屏及全天体验仍需实际试用。

本轮新增 **`artifacts/install-v0310/Pausewell-0.3.10-win-x64-install.zip`**。完整解压后双击 `Install.cmd`，完成后从开始菜单打开“间歇 Pausewell”。程序按当前用户安装，数据沿用 `%LOCALAPPDATA%/PausewellPrototype`，不自动导入各版本 demo 数据。已有旧版需先从托盘退出。

此包由本地工具构建，提供可审查的 PowerShell 一键安装脚本，**不是标准签名安装向导**。测试使用隔离目录，未写真实卸载注册表或快捷方式；真实注册安装、代码签名、全天办公和设备验收仍待完成。当前仍为集成试用阶段。

## 运行

- 体验本轮版本：双击 `体验办公观测版.cmd`。普通示例启用，药物示例停用；提醒按真实时间触发，退出应用后不再提醒。记录随实际操作产生，初次打开记录页为空。本地诊断保存在试用目录的 `diagnostics` 子目录。
- 体验旧版界面：双击根目录 `体验新版界面.cmd`。使用独立示例数据，支持真实操作和调度；不读取现有提醒数据。演示药物默认停用。
- 本轮正常使用：先在旧版托盘菜单中退出旧版，再解压本轮安装 ZIP 并运行 `Install.cmd`。首次没有现有正常数据时，页面为空，保存启用的计划后自动恢复提醒。
- 历史 v0.2 入口：`启动新版间歇.cmd`、`artifacts/Pausewell-ui-v02/Pausewell.exe` 仅供保留旧阶段，不作为本轮入口。
- 原发布目录 `artifacts/Pausewell-win-x64` 和旧入口保留，本轮没有覆盖旧程序。

v0.2 自包含，无需安装 .NET 或管理员权限。首次没有预先创建的真实计划；保存第一个启用计划后开始提醒，以后打开自动恢复。开机启动是设置中的独立可选项，默认关闭。

## 已接入的流程

- 提醒、服药、记录、设置四个导航入口；明确状态、下一次和当前待办。
- 普通完成后间隔、每日明确时刻、可选办公日时段；每条独立启停与编辑。
- 有期限的会议及普通暂停、延长与提前结束、30 秒会后缓冲、逐项待办。
- 独立药物计划、起止日期、明确时刻、已服用/未服用/待核实、实际时间与确认时间分开保存。
- 记录筛选、详情与带原因的更正历史，更正不移动未来计划。
- 暖香槟、灰紫、陶土橙、雾玫瑰、雾蓝五种主题；本窗口预览、保存全局应用、取消恢复、重开沿用。默认石墨黑主按钮、暖香槟色开关。
- 醒目弹窗、活动计时、如厕当前无需、全屏长按紧急退出、托盘驻留。

完成情况由用户确认。延期、关闭、不确定和当前无需分别记录，不自动视为完成。

## 数据与升级

正常数据：`%LOCALAPPDATA%/PausewellPrototype/pausewell.db`。直接 `--demo` 默认使用 `%LOCALAPPDATA%/PausewellPreview`，根目录演示入口指定项目内 `artifacts/ui-v02/demo-data`。设置中可打开当前数据目录。

首次读取 schema 1 数据时，先用 SQLite 一致性备份生成 `pausewell.db.before-v02-时间戳.db`，再升级至 schema 2。原计划与既有记录保留，不把旧记录的未知实际时间编造为确认时间。旧版程序不能直接读取升级后的数据，因此正式切换前保留备份；不要用旧版覆盖 v0.2 数据库。

本轮验收只使用新建独立数据和合成的旧版快照，没有迁移或改写正在运行的旧版数据。

## 设计与实现范围

界面保留选定的暖色玻璃层次、石墨主动作和香槟开关。主窗口、编辑表单、任务窗口及记录详情均使用共享材质；采用应用内背景采样、局部模糊、边缘高光和阅读层，文字控件不参与背景模糊。当前实现不包含 Apple 平台的实时折射引擎。标准图标采用 Microsoft Fluent System Icons，许可证位于 `Assets/Icons/LICENSE.txt`。

已进行规则、原生窗口、SQLite、真实时钟到期和常规/紧凑窗口检查。真实锁屏、睡眠、屏幕共享、多个显示器与多种 DPI 仍需后续设备试用；单显示器测试不能证明多屏覆盖效果。轻提醒仍受 Windows 通知设置控制。

当前普通间隔基于持久化时间戳；修改系统时间会影响间隔。固定时刻按中国标准时间解释。尚无云同步、自动会议识别、签名安装包、自动更新和长期连续稳定性验收。数据库本地保存但未加密。
